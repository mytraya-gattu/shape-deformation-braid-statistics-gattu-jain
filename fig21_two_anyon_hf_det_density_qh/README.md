# Fig. 21: single-determinant two-QH state, before and after vortex attachment

Density `2 pi rho(x,0) lstar^2` of the single-determinant two-quasihole state of Eq. (109), alpha = 2/3, with one QH at the origin (k1 = 0) and the other at omega = 10 lstar in state k in {0, 1, 2}. Results obtained via quadrature.

## Files
`panel_k0.csv`, `panel_k1.csv`, `panel_k2.csv` (one per panel k = 0, 1, 2).

## Columns
1. `x / lstar`: position along the x axis
2. `nu_noninteracting`: two independent anyons (reference)
3. `nu_before`: determinant alone (before vortex attachment)
4. `nu_after`: after vortex attachment, (z1 - z2)^alpha
