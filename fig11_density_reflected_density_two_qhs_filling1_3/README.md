# Fig. 11: two QHs at nu = 1/3

Density `2 pi rho(x,0) lB^2` along the line joining two quasiholes at nu = 1/3, N = 64, centered at +/- 6 lB (separation 12 lB), with k1 = 0 and k2 = 0, 1, 2 (conventional CF wave functions). Results obtained via Monte Carlo integration.

## Files
`density_N64_nu1_3_omega12.0_k1_0_k2_{0,1,2}_conventional.csv`

## Columns
1. `x / lB`: position along the cut
2. `2 pi rho(x,0) lB^2`: density (mean)
3. `Delta (2 pi rho)`: standard error
