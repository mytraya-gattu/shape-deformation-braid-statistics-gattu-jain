# Fig. 4: single-determinant two-QP state, before and after vortex attachment

Density `2 pi rho(x,0) lstar^2` of the effective two-anyon state built from the modified orbitals of Eq. (13), alpha = 2/3, one anyon at the origin (k1 = 0) and the other at omega = 10 lstar in the k state, k = 0, 1, 2. Exact (quadrature).

Files: `panel_k{0,1,2}.csv`.

Columns: `x_over_lstar`, `density_noninteracting` (two independent anyons), `density_before_vortex` (the Slater determinant alone), `density_after_vortex` (after multiplication by (Z1 - Z2)^alpha).

Script: `scripts/plot_hf_det_before_after_qp.jl` (repository `two_anyon_hf`).
