# Fig. 22: single-determinant (HF) versus conventional two QPs

Density `2 pi rho(x,0) lB^2` for two quasiparticles at nu = 1/3 (N = 80, omega = 15 lB) and nu = 2/5 (N = 80, omega = 18 lB), k1 = 0, k2 = 0, 1, 2, comparing single-determinant (Eq. 112, red curves) and conventional (black curves) wave functions. Results obtained via Monte Carlo integration.

## Files
`two_qps_density_N80_nu{1_3,2_5}_omega*_k1_0_k2_{0,1,2}_{hf,conventional_reference}.csv`

## Columns
1. `x / lB`: position along the cut
2. `2 pi rho(x,0) lB^2`: density (mean)
3. `Delta (2 pi rho)`: standard error
