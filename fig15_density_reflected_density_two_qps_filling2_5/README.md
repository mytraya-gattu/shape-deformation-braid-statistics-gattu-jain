# Fig. 15: two QPs at nu = 2/5

Density `2 pi rho(x,0) lB^2` along the line joining two quasiparticles at nu = 2/5, N = 80, centered at +/- 9 lB (separation 18 lB), with k1 = 0 and k2 = 0, 1, 2 (conventional CF wave functions). Results obtained via Monte Carlo integration.

## Files
`two_qps_density_N80_nu2_5_omega18.0_k1_0_k2_{0,1,2}_conventional.csv`

## Columns
1. `x / lB`: position along the cut
2. `2 pi rho(x,0) lB^2`: density (mean)
3. `Delta (2 pi rho)`: standard error
