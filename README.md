# shape-deformation-braid-statistics-gattu-jain

Processed numerical data for the paper *Shape Deformation and Braid Statistics of Fractional Quantum Hall Quasiparticles* (M. Gattu and J. K. Jain). One directory per data figure of the paper (schematics are not included), named `figNN_<figure file>` after the figure file in the manuscript. Every directory has a README giving the source script, the columns, and units.

Format: plain CSV, one header line naming the columns, then numbers. For Monte Carlo quantities the columns are the mean over chains and its standard error; for exact (quadrature or closed-form) quantities only the value is given.
