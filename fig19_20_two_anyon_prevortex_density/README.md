# Figs. 19 and 20: flux-dressed two-anyon states before vortex attachment

Density `2 pi rho(x,0) lstar^2` of the flux-dressed two-QP (Fig. 19) and two-QH (Fig. 20) states with the vortex factor removed, with one anyon at the origin (k1 = 0) and the other at omega = 10 lstar in state k. Results obtained via quadrature.

## Files
- `two_anyon_prevortex_density_qp.csv` (Fig. 19: two QPs)
- `two_anyon_prevortex_density_qh.csv` (Fig. 20: two QHs)

## Columns
1. `x / lstar`: position along the x axis
2-5. `k = 0` for alpha = 0, 2/7, 2/5, 2/3
6-9. `k = 1` for alpha = 0, 2/7, 2/5, 2/3
10-13. `k = 2` for alpha = 0, 2/7, 2/5, 2/3

(alpha = 0 is the noninteracting reference curve.)
