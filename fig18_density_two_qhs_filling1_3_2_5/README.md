# Fig. 18: conventional versus flux-dressed two QHs

Density `2 pi rho(x,0) lB^2` for two quasiholes at nu = 1/3 (N = 64, omega = 12 lB) and nu = 2/5 (N = 80, omega = 15 lB), k1 = 0, k2 = 0, 1, 2, comparing conventional (Eq. 33) and flux-dressed (Eq. 99) wave functions. Results obtained via Monte Carlo integration.

## Files
`density_N{64,80}_nu{1_3,2_5}_omega*_k1_0_k2_{0,1,2}_{conventional,corrected}.csv` (`corrected` = flux-dressed).

## Columns
1. `x / lB`: position along the cut
2. `2 pi rho(x,0) lB^2`: density (mean)
3. `Delta (2 pi rho)`: standard error
