# Figs. 25 and 26: norms of two-QH and two-QP states on the sphere

Norms of two-quasihole (Fig. 25) and two-quasiparticle (Fig. 26) CF states on the sphere as a function of relative angular momentum at nu = 1/3, 2/5, 3/7 for several N, compared with the two-anyon prediction (1 - x)^(alpha/2). Results obtained via Monte Carlo integration.

## Files
`{qh,qp}_N{...}_nu{1_3,2_5,3_7}.csv`

## Columns
1. `x`: relative angular momentum coordinate (scaled as horizontal axis of the figure)
2. Norm (mean)
3. Standard error on norm
4. Rescaled norm (as plotted in figure, matching first point to reference curve)
5. Standard error on rescaled norm
